# v2.6.5 · 夜谷全面视觉与窗口交互修复

## 主要变化

- 修复窗口缩放到 820px 及以下时非 Today 页面导航与主体互相挤压、内容近似消失的问题；窄屏统一为可滚动的顶部导航与单列内容。
- 按概念图重绘左上角薄荷色轨道图标，收紧活动 Tab 的圆角、边框和暖金到薄荷的亮度渐变。
- 收紧专注计时阶段路径的节点节奏，增加连续的上下蜿蜒，避免中段长距离平直。
- 将横向路径和页面滚动条默认隐形，并为超过五段路径提供左右按钮，降低视觉噪声且保留可操作入口。
- 修正 Today 右侧“下一站”面板的内部坐标、圆环尺寸和“开始专注”按钮宽高，恢复完整可见的“下一站”标签。
- 在无边框主窗口右上角恢复最小化、最大化/还原和关闭（隐藏到托盘）控件。
