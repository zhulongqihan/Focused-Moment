# Focused Moment v1.7.0 核心执行流版

## 核心变化

- 新增独立倒计时：可设置 1 至 720 分钟，支持开始、暂停、重置、到点提醒和完成记录。
- 倒计时运行状态会随现有计时状态一起本地保存，异常关闭后可以恢复。
- 专注首页收敛为计时模式、任务选择、计时显示和主要操作；不再让插画和状态概览占据开始路径。
- 首页直接显示最近三条专注记录，完成一轮后可立即确认是否已经落盘。
- 待办任务新增“开始专注”，点击后会自动关联任务并启动当前选择的计时模式。

## 兼容性

- 保留既有正向计时、番茄钟、待办、记录、备份和恢复数据。
- 旧版本地运行状态和备份没有倒计时字段时，会使用 25 分钟作为倒计时默认值。
