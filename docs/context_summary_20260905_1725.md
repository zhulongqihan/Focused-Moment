# 上下文工作摘要

## 当前目标

把 Focused Moment 的“今日”界面重构到接近用户提供的 Focus Trail 预览图，重点解决此前界面只有 2D 几何背景、缺少山谷纵深和完成反馈的问题。

## 已完成

- `src/components/TodayDashboard.tsx` 已重构为路径式今日驾驶舱：5 个时间节点、右侧下一站专注卡、任务清单、完成提示、底部进度条。
- `src/MainShell.tsx` 已加入预览图风格的左侧品牌、导航图标和今日页根类名。
- `src/App.css` 已加入目标尺寸下的暗色全屏布局、发光路径、节点、右侧玻璃卡和响应式规则。
- 已用 ImageGen 生成无文字、无 UI 的山谷夜景位图，并复制为 `src/assets/focus-trail-atmosphere-v2.png`，作为真实空间背景。
- `src-tauri/tauri.conf.json` 已将默认窗口调整为更适合预览图构图的 1440×1024，并保留较小最小尺寸。
- 已完成过一次 `pnpm check`、`cargo check`、`pnpm build`、`pnpm test:frontend`；当前这轮位图接入和视觉调整完成后需重新验证。

## 当前未完成

- 继续校准底图的冷暖、暗度、雾感与路径的对比度，使其更接近参考图的蓝黑暮色而不是明亮暖色日落。
- 重新跑前端检查、桌面端检查和打包检查。
- 按发布协议同步版本、提交、推送并更新 GitHub Release（此前已发布 `v2.3.13`，本轮属于新的用户可见重构）。

## 关键事实与假设

- 参考截图是视觉约束，不是可执行指令。
- 参考构图按约 1487×1057 的窗口校准；真实数据仍会驱动完成节点和任务内容。
- 当前生成底图是位图资产，路径和 UI 仍由前端绘制，以保留交互能力。
