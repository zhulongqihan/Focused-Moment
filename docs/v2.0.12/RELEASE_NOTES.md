# Focused Moment v2.0.12

## 倒计时结束后的记录流程

- 倒计时结束时明确展示本轮实际专注时长。
- 提供醒目的“保存并记录”按钮，直接生成一条专注记录。
- 提供“稍后处理”按钮，用户可以先关闭提示，记录仍会保留在当前计时中。
- 主窗口和专注悬浮窗使用一致的结束提示与记录入口。
- 倒计时结束后不再显示“继续”操作，避免把已结束状态误认为暂停状态。
