# v2.4.0 · 今日路径空间重构

## 主要变化

- 将“今日”页重构为与 Focus Trail 预览一致的路径式工作台：左侧导航、今日路径、节点状态、下一站专注卡和底部进度形成同一套视觉系统。
- 使用真实的山谷暮色背景板、远近山体、雾层、道路和灯塔，替代原来的 2D 几何山形；背景支持轻微指针景深位移，并遵守减少动态效果设置。
- 统一日期、标题、节点、计时环、任务行、快捷命令和导航图标的字体、线宽、基线与颜色层级。
- 保留真实数据驱动：完成的专注记录会点亮节点，完成 3 段后显示“已到达”反馈，右侧任务仍可直接进入专注或待办。
- 保留顶栏拖拽热区、命令面板、计时、待办、记录和设置等原有交互。
