# v2.6.0 · 全面氛围化工作台

## 这次更新

- **所有 tab 统一到深夜山谷视觉体系**：今日、计时、待办、记录、设置共享同一套夜景背景、玻璃层、金色路径线、薄荷色文字和状态反馈。
- **计时页重构**：保留正向计时、倒计时、关联待办和保存记录能力，改为聚焦单一任务的圆形计时舱，并在窄屏下保持按钮与读数完整可见。
- **待办页重构**：输入区、待办列表、完成态、逾期态和行内操作全部改为暗色工作台，操作按钮在窄屏下仍保持可读、可触达。
- **记录页重构**：新增真实数据驱动的「专注档案」轨迹，按最近 7 天展示节点、投入强度和选中日期详情；记录数量不限于 5 段，支持节点选择、日期回看和原有编辑/删除能力。
- **记录页响应式修复**：窄屏使用独立的横向轨迹画布，日期节点不会互相遮挡，页面本身不产生横向溢出；历史记录卡片与详情面板保持统一风格。
- **设置页重构**：提醒、音效、本地备份、恢复备份和清空数据按深色分区呈现，保留现有数据安全与系统提醒操作。
- **成就反馈文案更新**：今日页以「今天已留下 N 段专注」描述无上限的每日路径，完成一段就新增一个坐标，不再暗示固定的 5 段上限。
