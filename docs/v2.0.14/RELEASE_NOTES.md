# Focused Moment v2.0.14

## 记录页复盘优化

- 新增更明确的专注成就总览，突出连续投入和最佳单日。
- 用最近 7 天柱状趋势替代冗长的横向进度条，并补全无投入日期。
- 专注记录按日期收纳，默认展开最新一天，历史日期可按需展开。
- 记录条目显示模式标签、完成时间和时长，保留逐条删除与撤销能力。
- 窄窗口下保持统计、趋势和记录操作可用，不产生横向溢出。
