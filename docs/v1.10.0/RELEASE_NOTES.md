# Focused Moment v1.10.0 体验闭环与数据掌控版

- 待办支持截止时间、重要程度和编辑，前端排序与后端规则保持一致。
- 完成专注时可以同步标记关联待办，正向计时小窗也能调整该选项。
- 增加设置页，支持导出备份、查看备份、打开备份目录、导入恢复和清空当前数据。
- 备份默认保存到用户数据目录，同时兼容旧版本安装目录中的备份。
- 记录页增加最近 7 天专注趋势。
- 增加刷新请求并发保护，避免旧数据覆盖刚完成的操作，并自动清理已恢复的错误提示。
- 增强待办标题、日期和时间的数据校验。
- 修正中文页面语言、导航选中状态、模式按钮状态和表单标签。
- 增加基础 GitHub Actions 校验流程。
- 版本同步至 1.10.0。
