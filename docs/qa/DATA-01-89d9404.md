## 运行时事实

- Windows 默认数据目录为 `%LOCALAPPDATA%\FocusedMoment`，macOS 默认数据目录为 `~/Library/Application Support/FocusedMoment`；用户备份在各自目录下的 `Focused Moment Backups`。
- 用户备份是明文 JSON；本轮没有新增加密、云同步或网络传输。
- `docs/content/copy-library-sources.md` 现有语料来源说明完整记录 1000 条语料和运行时离线策略；其提到的 `npm run copy:validate` 当前并未在 `package.json` 注册，本轮已作为清单缺口记录，没有声称命令已运行。
