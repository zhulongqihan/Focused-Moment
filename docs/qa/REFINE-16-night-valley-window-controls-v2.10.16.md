# REFINE-16 · Night Valley 记录页窗口控件交互（v2.10.16）

## 用户问题

用户反馈记录页修复后，右上角最小化、最大化/还原和关闭三个窗口控件无法使用，导致无法继续检查页面。

## 根因

无边框主窗口把整个顶栏绑定到 `mousedown` 拖拽处理；窗口控件位于同一 DOM 冒泡链中。浏览器 mock 能命中按钮，但 Windows WebView2 点击 SVG 图标时可能先进入窗口拖拽路径，导致控件动作被吞掉。另经现场状态核对，用户当时仍有 `Focused Moment v2.10.14.exe` 进程占用单实例互斥锁，直接启动 v2.10.15 会退出并把焦点交回旧进程，容易把旧行为误判为新版本回归。

## 修复

- 顶栏拖拽判断显式排除 `.window-controls`。
- 窗口控件容器停止 `mousedown` 冒泡，保证最小化、最大化/还原和隐藏到托盘动作独立接收点击。
- 增加记录页三控件命中、命令调用和不触发拖拽的前端回归断言。

## 验收边界

- 只修改共享顶栏事件保护、测试和版本/文档同步。
- 保留 Windows 单实例行为；升级检查时需先退出旧版本进程，再启动新版本。
- macOS 不构建、不上传、不运行 workflow。
