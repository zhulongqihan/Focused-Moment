## 几何与尺寸证据

固定构图下五页都没有横向溢出，公共导航为 `x=0, width=130`，页面根区域从 `x=130` 开始；计时右侧面板在基准视口内为 `right=1447`。设置页主布局的 `bottom=1080`，高于视口底部 `1058`，因此它必须依靠页面滚动，不能被当作“所有设置内容在首屏完整可达”。

新增矩阵覆盖：

- Tauri 默认窗口代理：`1440×1024`。
- 配置最小主窗口：`1120×760`，对应 `src-tauri/tauri.conf.json`。
- 最大化代理：`1920×1080`。
- DPR 代理：`1.25 / 1.5 / 2`，对应 125% / 150% / 200% 的浏览器几何压力。

六种场景的五页 `scrollWidth` 均不超过视口宽度，面板左右边界也未越界。当前 Windows 注册表 `LogPixels=144`，表示主机当前记录为 150% 缩放；本轮没有修改系统显示设置，所以 DPR 代理不能替代 125%/150%/200% 的原生 Tauri 窗口实测。

沿用计划中的同环境阈值：面板边界/节点中心 ≤2 px、路径中心线 ≤3 px、同文案文字基线 ≤2 px、同文案宽度尽量 ≤3%。本轮只证明当前实现的几何值和边界，不证明它已经达到参考图的一比一阈值；参考图没有可执行的同 fixture DOM，也没有源字体/分层素材。
