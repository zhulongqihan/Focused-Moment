# NV-05 交互、响应式与错误态验收

- 日期：2026-09-08
- 源码提交：`85308f1`
- 执行环境：Windows 11、Chromium、Tauri mock、Playwright 1.62.1
- 版本：`2.6.9`（本轮未改版本与 Release 资产，交由 REL-01 统一收尾）

## 本轮收口

1. `CommandPalette` 改为可追踪活动选项的 listbox：搜索框保持焦点，支持 ArrowUp/ArrowDown/Home/End、Enter 执行、Esc 关闭；选项通过 `aria-activedescendant`、`aria-selected` 和稳定 ID 暴露。
2. 对话框只在关闭按钮和搜索框之间循环 Tab/Shift+Tab，选项保持 `tabIndex=-1`，避免 Tab 落入背景或隐藏操作；鼠标悬停、点击和键盘执行共用同一命令回调。
3. 增加启动本地数据失败 → 可见错误 → 重试恢复的 mock 回归；补充 Space、Tab、Enter、Esc、无匹配命令等键盘路径。
4. 在 `1120×760`、`820×720`、`560×720` 压力窗口覆盖今日、计时、待办、记录、设置五页，验证 surface 不横向溢出；Today 路径回到起点时首节点标签不越过 viewport 边界；Settings 本地备份锚点、导出备份、清空数据均可进入视口并获得焦点。
