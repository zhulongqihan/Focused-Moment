# DESK-01 · Windows 原生闭环

## 结论

**核心 Windows 原生冒烟通过，任务完成。** 本轮发现并修复一个真实运行时缺口：开始计时调用的 `show_focus_floating` 原先误打开 `todo-float`，并隐藏真正的 `focus-float`；修复后计时会进入专注小窗，且专注小窗的锁定/独立解锁链路可用。

- 版本：`2.6.9`
- 源码基线：`a52796f`
- 修复提交：`7fd5766`
- 系统：Windows 11 专业版，版本 `10.0.26200`，64 位
- WebView2 Runtime：`152.0.4191.66`
- 原生窗口 DPI：`144`（150%），屏幕 `2560×1440`
- 主窗配置：`1440×1024`，最小 `1120×760`；原生运行时窗口物理尺寸约 `2182×1466`，与 150% DPI 一致
- 测试数据目录：`%TEMP%\focused-moment-desk-01-focus-float-a52796f\FocusedMoment`；未读取或写入真实用户数据
