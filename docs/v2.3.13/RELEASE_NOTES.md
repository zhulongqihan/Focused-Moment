# Focused Moment v2.3.13

## 今日路径：把专注变成一条看得见的路

- 重构“今日”主页为深色专注轨迹地图，集中呈现下一件事、当前计时和今日路径。
- 待办、计时、完成记录保持在同一条连续路径中，点击“开始下一件事”后留在今日页进入运行态。
- 完成一轮专注后提供“已到达 · +1 节点”反馈，让本地记录带来明确但不焦虑的成就感。
- 路径节点、下一站面板、任务折叠区和专注记录入口支持键盘焦点、窄窗口布局与减少动画偏好。
- 其他页面、悬浮工作台、命令面板、本地备份和数据存储逻辑保持兼容。
