# v2.0.0 验收矩阵

| 领域 | 必须成立的结果 | 证据 |
| --- | --- | --- |
| 首次使用 | 打开后能看到当前状态、下一任务和开始入口 | 浏览器快照 + Windows 冷启动冒烟 |
| 专注闭环 | 待办可一键进入专注，完成后记录与待办状态一致 | 前端流程测试 + Rust 测试 |
| 视觉交互 | 空闲、运行、暂停、休息、恢复状态可区分且不遮挡操作 | 多窗口尺寸截图 + 无障碍检查 |
| 复盘 | 统计可解释、空数据不误导、能给出下一步 | 边界数据测试 + 手工复核 |
| 数据升级 | v1.10.0 数据无损进入 v2，失败可回滚 | 迁移夹具 + 损坏备份测试 |
| 稳定性 | 旧请求不会覆盖新操作，异常关闭可恢复 | 并发模拟 + 重启冒烟 |
| 发布 | 版本源同步、构建、安装包、Release 和文档一致 | CI、打包清单、GitHub Release |

## 阻断项

- 任何任务、记录或运行中计时数据丢失。
- 计时状态、待办状态和记录状态互相矛盾。
- 主要操作无法用键盘完成或焦点不可见。
- 默认、最大化或窄窗口出现文字重叠、横向溢出或按钮不可用。
- 发布包版本与页面版本不一致。
