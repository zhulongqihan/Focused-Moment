# Focused Moment v2.0.0

## 专注闭环版

Focused Moment 2.0 将入口从“打开一个计时器”升级为“打开就知道下一步”。它仍然是 Windows 本地优先的小工具：无账号、无云同步、无遥测，数据留在本机。

### 这次更新

- 新增“今日”驾驶舱：打开应用即可看到当前状态、下一件待办、今日投入和连续节奏。
- 新增 Focus Arc 状态氛围：空闲、运行、暂停和休息阶段有清晰但克制的视觉反馈。
- 新增应用内命令面板：使用 `Ctrl + K` 搜索页面、开始/暂停/完成专注和导出备份。
- 新增连续投入和最佳投入日复盘，统计只基于本地已有记录，不做评分和排名。
- 支持 v1 备份自动迁移到 v2 格式，保留待办、记录、偏好和未完成计时状态，并提供迁移前回滚备份。
- 设置页增加备份摘要，恢复前可看到版本、待办数、记录数和运行中会话。
- 抽离今日驾驶舱和命令面板组件，补充前端流程测试、Rust 边界测试和 CI 门禁。

### 兼容与安全

- v1.10.0 的本地状态和备份可以无损迁移。
- 新版本备份不会被旧版本静默导入；无法识别的格式会明确拒绝。
- 清空数据仍不会删除已经导出的备份文件。

### 验证

- 前端类型检查、生产构建和 Playwright 流程测试通过。
- Rust 格式检查、编译检查和 7 项单元测试通过。
