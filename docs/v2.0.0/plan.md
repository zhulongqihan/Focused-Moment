# Focused Moment v2.0.0「专注闭环」

## 产品承诺

打开应用后，用户能在 5 秒内知道当前状态和下一步，并在 3 个主要操作内从下一件待办开始专注。完成后，记录、待办和复盘保持连贯。

## 边界

- 保持 Windows、Tauri 2、本地优先、无账号、无云同步、无遥测。
- 不引入游戏化积分、排行榜和压力型通知。
- 允许调整内部数据模型，但 v1.10.0 数据必须无损迁移并可回滚。
- 快捷键限定在应用内，不做全局系统热键。

## 七轮迭代

1. 基线治理：校准文档、调用链、验收矩阵和迁移边界。
2. 今日驾驶舱：收敛当前状态、下一件任务和一键开始路径。
3. Focus Arc：建立运行态视觉系统、命令面板和无障碍交互。
4. 可行动复盘：用本地数据讲清今天做了什么和下一步做什么。
5. 数据迁移：完成 v1 → v2 无损迁移、备份预览和回滚。
6. 工程收束：拆分前端壳层、治理并发、补齐自动化测试和 CI。
7. 独立审阅：从研发、用户、产品、业务和发布五个视角验收并发布。

## 每轮固定动作

- 读取本文件和 `iteration-log.md`，确认上一轮门槛。
- 先写问题假设，再实现最小闭环。
- 运行静态检查、自动化测试和浏览器/Windows 场景验证。
- 记录已验证事实、未解决风险和下一轮输入。
- 未通过 P0/P1 门槛时，不进入下一轮。
