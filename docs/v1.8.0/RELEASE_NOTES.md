# Focused Moment v1.8.0 极简专注工作流版

## 重构

- 主窗口彻底收缩为“计时、待办、记录”三个页面。
- 移除主界面的番茄钟入口、复盘、备份、设置、插画、星图和复杂筛选，旧数据与计时引擎仍保留兼容。
- 待办创建收敛为事项和截止日期；待办列表可直接进入专注。
- 正向计时要求为每轮填写或关联事项，完成后会保存实际坚持时长。
- 倒计时可设置 1 至 720 分钟，并在到点后完成记录。

## 透明悬浮待办

- 新增透明、无边框、置顶、可调整大小的桌面待办窗口。
- 点击主窗口“悬浮待办”后，主窗口隐藏，只保留待办浮窗。
- 浮窗可直接勾选完成待办，并可返回主窗口。

## 数据兼容

- 原有待办日期继续作为截止日期使用。
- 原有专注记录不会迁移或删除，包含此前的番茄钟记录。
