# Focused Moment v2.14.2

本说明汇总自公开版本 v2.11.10 以来的 Windows 更新：从临时记下一件事，到开始专注、保存记录和下次继续，日常操作更加连贯；保存恢复与多窗口同步也得到改进。

## 待办、专注和继续位置

- 快速记事支持不填日期，先放进「收件箱 · 未安排」，之后再安排时间。
- 可以设置当前事项和最多 3 个今日精选，并从待办开始专注。
- 七种主题首页使用一致的开始、暂停、继续和完成操作。没有可继续事项时，主操作打开快速记事。
- 同一待办可以关联多轮专注；完成一轮不会自动勾完待办。
- 完成后可保存停笔书签，下次继续时看到上次的位置。专注浮窗完成后，主窗口接手书签提示，支持保存或跳过。
- 专注记录支持手动补录，以及标题、时长、完成日期时间和关联待办的修正；命令面板可搜索和回看任务、记录与日期。

## 主题与交互

- 常用主题为「夜谷」「编辑纸页」「石墨控制台」「今日班次」「今日赛场」。原「极光海面」「植物书房」保留在设置的「旧版主题」中。
- 今日班次和今日赛场覆盖首页、计时、待办、记录和设置；图表、摘要及任务动作均使用真实数据。
- 主题切换按需加载，加载期间保留当前界面；失败可重试，迟到的加载结果不会覆盖最近的选择。
- 弹层完善键盘焦点、Tab 循环、Escape、输入法组合确认和关闭后的焦点恢复；保存期间阻止重复提交及误关闭。
- 自定义音效的试听和自动提醒使用同一音源；主窗口统一负责发声，避免多个窗口重复提醒。旧趣味语音已移除。

## 保存、恢复与备份

- 数据与计时状态共用事务保存和崩溃恢复机制，减少中断写入造成的两份状态不同步。
- 保存成功后的统计刷新或窗口恢复失败会单独提示；重试后续操作不会再次保存同一条记录。
- 重置未完成计时前显示确认，默认保留本轮；其他窗口的过期确认不能清除新的计时会话。
- 完整备份升级到格式 v3、schema v3，包含待办、记录、今日计划、计时状态、应用偏好与自定义音效。
- 支持选择外部 JSON、先预览后导入；可选择是否同时恢复主题、视觉设置和音效，导入前自动生成回滚备份。
- 修复 Windows 数据导入和清空操作未等待确认的问题；取消或确认框失败时保留数据，等待确认期间阻止重复提交。外部导入必须使用已经预览的文件。
- 遇到事务恢复冲突时暂停新的写入，并提供恢复材料导出。

## 启动与持续运行

- 主窗和浮窗按业务域版本读取发生变化的数据；空闲时不再每秒读取和广播完整业务状态。
- 慢请求合并处理，旧响应不会覆盖新状态；版本定期校准，读取失败后自动重试。
- 计时使用轻量快照，音频仅在音源变化时单独读取；浮窗不重复加载音频。
- 默认首页首次可操作前实际加载的 JavaScript 从 934,750 bytes 降至 228,261 bytes，较 2.14.0 基线减少 75.58%。该数字是首页交互前的加载量，后续页面和语料仍按需加载。
- 七张主题预览改用 640×455 WebP，合计 266,706 bytes；原始 PNG 保留。

## 升级说明

- 建议升级前在旧版导出并保留完整备份。新版本可迁移 v1/v2 备份；新导出的 v3 备份不作为旧版本可读取的回退文件。
- 旧主题 ID `aurora-ocean`、`botanical-library` 会分别映射到今日班次、今日赛场；需要原主题时，可在设置的「旧版主题」中重新选择。
- 外部备份导入会替换当前待办、记录和计时状态，不会自动合并两份数据；恢复外观和自定义音效需要勾选对应选项。
- 当前交付范围为 Windows x64，macOS 发布继续冻结；没有新增账号或云同步。
