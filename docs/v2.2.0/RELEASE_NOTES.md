# Focused Moment v2.2.0

## 经典语料库与每日一句

- 将每日一句扩展为 1000 条本地语料：885 条中文古典原文、115 条英文公版作品节选及中文编辑译文。
- 每天根据本地日期从稳定打乱后的语料顺序中选取一句；同一天展示稳定，连续 1000 天不会重复，不依赖专注轮次、时长或连续记录。
- 英文条目优先展示中文译文，同时保留英文原文、作者与作品信息。
- 语料以 JSON 随应用打包，运行时不请求网络；来源、许可和校验报告保存在 `docs/content/`。

## 验证

- 前端类型检查、生产构建、前端自动化测试、Rust 测试与 Windows 安装包构建均通过。
