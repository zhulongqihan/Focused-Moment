# 数据备份与换机

本文对应 Focused Moment 2.14.2：备份格式和存储 schema 均为 v3。完整备份是独立的 JSON 文件，包含待办、专注记录、未完成计时、今日计划，以及主题和自定义音效等应用偏好。

当前发布和验收范围为 Windows x64。macOS 公开版本仍冻结；旧版 macOS 应用不能据此视为支持 v3 备份。

## 导出与恢复

今日班次和今日赛场的设置页需要先展开「完整 JSON 文件备份 · 选择文件、预览与导入」，即可看到下面的操作入口。

1. 在源设备的「设置」中找到「完整备份与恢复」，点击「选择导出位置」，选择一个 `.json` 文件，再点击「导出到此路径」。也可以使用主题设置页的「导出备份」将文件保存到应用备份目录。
2. 保留源设备上的数据，把导出的 JSON 复制到新电脑上的安全位置。
3. 在目标设备安装支持 v3 备份的版本，打开「设置」→「完整备份与恢复」，点击「选择 JSON 文件」，选中备份后点击「预览」。文件无需先放进应用备份目录。
4. 核对应用版本、格式、待办和记录数量、未完成计时及外观与音效信息。需要一起迁移外观和音源时，勾选「同时恢复主题、视觉设置和自定义音效」；该选项默认不勾选。
5. 点击「确认导入并生成回滚」，确认替换当前数据。应用会先保存目标设备的回滚备份，再执行导入。
6. 检查待办、记录、当前计时和停笔书签；若恢复了偏好，再核对主题并试听自定义音效。重新启动后确认数据仍在，再考虑归档源设备数据。

预览只读取文件，不替换当前数据。导入是替换，不会把两台设备的记录自动合并。

## 两种恢复入口

| 入口 | 数据与设置的处理 |
| --- | --- |
| 「完整备份与恢复」选择外部 JSON | 恢复待办、记录、计时设置、运行态和今日计划；可选择是否同时恢复应用偏好与自定义音效 |
| 主题设置页中的本地备份列表 | 恢复待办、记录、计时设置、运行态和今日计划；保留目标设备现有应用偏好与自定义音效 |

需要恢复全部外观与音源时，请使用第一个入口并勾选对应选项。恢复导入前的回滚文件也遵循相同规则。

## 备份内容

| 内容 | v3 备份保存的范围 |
| --- | --- |
| 待办 | 标题、完成状态、安排日期和时间、重要程度、停笔书签及其更新时间；未安排日期的收件箱事项也包含在内 |
| 专注记录 | 标题、实际时长、计时模式、完成日期和时间、关联待办、来源、修正信息及编号 |
| 今日计划 | 当前事项、今日精选及其引用；恢复时清理已失效的关联 |
| 计时设置与运行态 | 计时和提醒偏好、当前模式、已用时、倒计时目标、未完成会话、任务上下文及恢复所需状态 |
| 应用偏好 | 主题、视觉强度、动效、密度、浮窗透明度、开始时是否自动打开迷你工作台 |
| 自定义音效 | 导入音源的文件名和编码后的音频数据；恢复偏好时一并恢复 |
| 文件信息 | 备份类型、格式与 schema 版本、导出应用版本和时间 |

自定义音效的导入上限为 5 MiB。外部备份预览和导入接受不超过 32 MiB 的 JSON 文件；导出成功并不代表任意大小的文件都能通过外部导入入口读取。

已保存的停笔书签属于待办数据，会进入备份。尚未回答的书签提示、窗口显示状态、系统权限、应用安装包及内置图片和语料不属于个人备份内容。内置资源由目标应用版本提供。

## 版本兼容

- v3 应用可读取格式 v1、v2 和 v3 的完整备份；旧格式在导入时迁移，预览会显示格式或 schema 升级提示。
- v1/v2 备份不包含新版完整的应用偏好和自定义音源。恢复旧备份时，可保持「同时恢复主题、视觉设置和自定义音效」未勾选，以保留目标设备当前设置。
- 旧主题 ID `aurora-ocean`、`botanical-library` 分别映射到「今日班次」「今日赛场」。需要原主题时，可在设置的「旧版主题」中重新选择「极光海面」「植物书房」。
- 应用会拒绝不支持的备份格式、来自更高 schema 的备份、损坏的 JSON，以及不合法的计时设置或应用偏好；不要修改版本字段来绕过检查。
- 从 v2.11.10 升级前，请在旧版导出并保留原始 v2 备份。若需要回到旧版，应使用升级前的备份；v3 备份不作为旧版可读取的回退文件。

## 文件位置与回滚

| 平台 | 默认应用数据目录 | 默认用户备份目录 |
| --- | --- | --- |
| Windows | `%LOCALAPPDATA%\FocusedMoment` | `%LOCALAPPDATA%\FocusedMoment\Focused Moment Backups` |
| macOS 源码保留的路径 | `~/Library/Application Support/FocusedMoment` | `~/Library/Application Support/FocusedMoment/Focused Moment Backups` |

优先通过应用的「打开备份目录」找到本机实际位置。系统环境或回退目录可能不同，不要猜测路径后覆盖文件。

应用目录内生成的备份以 `focused-moment-backup-v3-` 开头；导入前的保护副本以 `focused-moment-backup-v3-rollback-before-import-` 开头。外部导出允许自行选择文件名。

`focused-moment-state.json`、`focused-moment-runtime.json`、对应的 `.backup.json` 和 `focused-moment-transaction.*` 是应用内部状态及事务恢复文件。请使用完整备份进行搬移，不要在运行时手工拼接、覆盖或删除这些文件。

导入或写入中断时，事务恢复会保留上一份完整状态，或确认已经提交的新状态。若日志损坏、回滚失败或校验冲突，应用会暂停新的写入并提供「导出恢复材料」。此时保留原现场，按提示导出材料再排查。

备份 JSON 和恢复材料可能包含任务标题、记录与自定义音频。反馈问题时优先提供操作步骤和隐去个人内容的截图，不需要公开上传完整数据文件。
