# Focused Moment 2.12.0

## 从想到到继续

本版本把“临时想到、开始专注、完成一轮、下次继续、修正和回顾”连接成一条本地优先的工作流。

### 新增

- 快速收进收件箱：不填日期即可保存为“收件箱 · 未安排”。
- 当前事项与最多 3 个今日精选，可从待办中心直接设定并开始真实计时。
- 一个待办可累积多条专注记录；结束一轮不会自动完成待办。
- 停笔书签：记录下次继续位置，并在下一轮开始前继续看到。
- 手动补录和详细修正：支持标题、时长、完成日期、时间和关联任务。
- 命令面板任务回顾：可搜索任务、记录和日期，并定位到关联记录或日期归档。
- v3 完整便携备份：支持外部 JSON 文件预览、选择性恢复外观和自动回滚。
- 迷你工作台统一入口，默认开始计时留在当前页面，可选自动打开。

### 体验调整

- Today 只呈现当前事项、今日精选和今日投入；长期统计集中到 Records。
- 五套主题继续保留，主题、视觉强度、动效、密度和迷你工作台偏好即时保存。
- 移除内置趣味语音，保留中性内置提示音和自定义音效；旧配置自动兼容为柔和铃音。
- 记录按完成日期归属，不伪造跨午夜区间。

### RC 修正

- 单独恢复待办、记录或设置时，不再替换未选择的计时运行态或计时设置；同时恢复待办和记录才恢复计时运行态。
- 备份先校验再确认；缺失数据域、非法字段和未来版本不会被当作空数据导入。中断的多文件恢复在下次启动时回滚。
- 未填写的记录时间保持未知；最近记录按完成日期和时间排序。
- 外观保存失败后保留当前修改，过期请求不再覆盖新的界面状态。
- 关闭窗口或从托盘退出前等待外观保存；失败时返回主窗口保留重试入口。
- 迷你工作台结束专注后，主窗口也能继续填写停笔书签；旧窗口入口统一进入工作台。
- 轻量修改记录标题不再改变精确时长；支持定位七天以前的日期及深层历史记录。
- Today 在已有计时时提供“查看当前专注”，长标题和窄窗口操作区保持可读。
- 命令面板键盘选择不再被后台刷新重置；同名自定义音频替换可同步到其他窗口，避免保存前提醒使用旧音频。

### 兼容与范围

- 存储 schema 与备份格式从 v2 升级到 v3，旧数据和旧备份提供幂等迁移。
- 本轮交付范围为 Windows；不包含重复任务、休息流、OS 全局快捷键、团队协作或 AI 总结。
