# v2.5.1 · 气氛化今日路径

## 主要变化

- 重做今日路径的视觉层：背景、远景雾、前景暗部、路线投影、路线高光和节点球体分层渲染，恢复概念图的空间感与灵动感。
- 移除右侧面板中没有数据来源的示例任务；无待办时只显示真实的下一段状态，不再凭空生成任务名称、数量或时长。
- 底部文案改为无上限的累计表达：每完成一段就留下一个新的坐标，不再使用带分母的进度语义。
- 没有任何记录或待办时，使用“今天的第一段”作为诚实的起点；下一段标题、时间和默认专注时长均跟随真实数据与偏好。
- 窄窗口提前切换为上下布局；多段路径保留横向轨道，并在加载后自动把当前段滚动到可见区域。
- 补充无待办状态和多段路径的前端回归测试。
