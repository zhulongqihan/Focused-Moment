## 审阅发现及根因级修复

| 问题 | 根因与处理 |
| --- | --- |
| 选择性恢复仍替换计时设置或运行态 | 原导入合并未按域隔离；仅选择对应设置才替换偏好，仅同时恢复 todos/records 才替换运行态。部分恢复保留 live timer 单调时钟 anchor。 |
| 两份存储文件的进程中断一致性 | 仅错误返回回滚不足；引入 before journal，提交点为删除 journal；重启访问前恢复四份原字节，损坏或恢复失败继续保护。 |
| 缺字段备份被当成空数据 | 解析层要求真实领域字段与 v3 设置字段；损坏、未来版本、非法字段均先拒绝，预览只读。 |
| 旧备份迁移来源丢失 | 校验迁移 clone，导入仍保留原始版本，避免二次解析误报 v3/no migration。 |
| 外部备份写到一半损坏已有文件 | 同目录临时写入并 sync 后原子发布；内部备份禁止同名覆盖，外部导出要求明确覆盖确认。 |
| 未填写时间被伪装成午夜 | 明确日期与空时间保持原义，各主题显示“未填写时间”，不造跨午夜区间。 |
| 仅改标题意外改变精确时长 | 轻量改名改用专用 title IPC，完整记录编辑才使用分钟字段。 |
| 删除/撤销记录留下旧统计 | 写入后重新获取 analytics；日期归属、累计、活跃日、连续天、最佳日和最近记录均有专项回归。 |
| 失败重试、刷新响应覆盖新外观 | 串行保存并维护修改版本，旧响应不重新应用；失败后新编辑使旧 retry 失效。退出等候队列完成，不延长 debounce 掩盖竞态。 |
| 托盘仍能创建旧独立专注窗 | 托盘与旧兼容 IPC 均指向同一 todo-float 工作台；无计时也允许打开待办标签。 |
| mini 完成记录后主窗没有书签入口 | 独立事件通知主窗读取已提交任务；不依赖状态事件先后，通知失败不撤销已保存记录。 |
| 大于七天的日期/深层记录搜索定位错误 | 日期定位使用全部日归档，记录使用精确 ID 筛选；清楚说明列表筛选与全局统计的不同范围。 |
| 自定义提醒只试听正常 | 实际提醒改为读取当前 Rust 配置中的音频，不依赖迁移后已清理的 localStorage。 |
| 同名音频替换与保存前广播竞态 | 仅在音频变化时计算短内容标记，事件不携带音频；按名称与指纹合并读取，拒绝迟到或尚未提交的字节，等待正确音频前不认领提醒序号。 |
| 键盘搜索选择被后台刷新抢走 | 新建列表DOM使静止指针触发mouseenter；改为实际mousemove才改变选择，并检查End选择跨两次后台刷新仍保持。 |
| 旧视觉测试退出默认回归 | 显式注册 101 项 legacy 测试，并逐项映射新信息架构；保留 8 项现有测试，再加 75 格主题/页面/尺寸矩阵。 |

## 从用户角度落实的建议

- 正在计时时提供“查看当前专注”，避免主操作永久灰掉、用户找不到正在进行的工作。
- 当前事项支持明确取消；精选按钮可访问名称说明“设为当前”，不让点击标题的效果靠猜。
- 长标题完整换行，窄窗口操作区可以换行；五套主题继续保留，不加入虚假卡片和仪表。
- 备份确认与成功反馈按实际选择列出恢复内容、计时边界和回滚文件名，不暗示未选内容也被恢复。
- 搜索后显示筛选对象、匹配条数与清除入口；说明累计统计和七日趋势仍是全局数据，避免误读为任务统计。
- 保存失败时保留本次界面效果和重试；退出不默默丢弃失败设置。

以上均在既定 RC 范围内；未借可用性建议扩展产品功能。
