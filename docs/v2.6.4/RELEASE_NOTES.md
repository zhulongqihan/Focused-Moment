# v2.6.4 · 夜谷窄屏布局修复

## 主要变化

- 修复 Windows 高 DPI 缩放或窗口拉窄到中等桌面宽度时，左侧导航被单独排到第一行、Today 内容被推到视口下方的问题。
- 保持左侧导航与 Today 主内容并排显示，并允许窄桌面窗口继续纵向滚动查看完整页面。
- 本版本只包含第 1 项窄屏布局修复，不改变其他待确认的视觉问题。
