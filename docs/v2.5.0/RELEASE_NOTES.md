# v2.5.0 · 自适应今日路径

## 主要变化

- 将今日路径从固定 5 个视觉节点改为真实数据驱动：当天的专注记录、已完成待办和待开始待办会按时间组成完整路线，支持任意数量的时段。
- 当路线超过当前窗口可安全展示的范围时，路径会进入独立横向轨道；线、节点和文字保持自己的尺寸，不再因为窗口缩放互相挤压或被右侧面板遮挡。
- 修复短窗口和窄窗口的裁切问题：桌面端允许自然纵向滚动，平板宽度改为路径与下一站上下堆叠，移动端保留横向浏览路线的交互。
- SVG 路线使用非缩放描边，节点文字使用独立 DOM 排版；调整窗口大小时，发光线条、节点圆环和字体不再被整体拉伸。
- 底部进度、下一站信息和到达提示同步使用动态段数，并在超过 5 段时提示左右滑动查看更多。
