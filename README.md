# Focused Moment

Focused Moment 是一个本地优先的 Windows 专注工具，只保留三件事：待办、正向计时和倒计时。

## 功能

- 待办：每项待办必须有截止日期；可在主窗口中管理，也可一键变成透明、置顶的桌面悬浮清单。
- 正向计时：记录每件事情实际坚持的时长，完成后保存在本地记录中。
- 倒计时：自行设置 1 至 720 分钟的专注时长，到点提醒后完成记录。
- 本地兼容：既有待办、正向计时、番茄钟和倒计时记录都会继续保留。

## 日常使用

1. 在“待办”写下事项与截止日期。
2. 点击“专注”将待办带入计时页，或直接写下一轮要做的事。
3. 选择正向计时或倒计时，开始后在完成时保存记录。
4. 需要桌面提醒时，点击顶部“悬浮待办”，主窗口会隐藏，只留下透明置顶待办窗口。
