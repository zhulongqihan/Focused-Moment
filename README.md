# Focused Moment 2.0

Focused Moment 是一个本地优先的 Windows 专注工具，让用户从下一件待办快速进入专注，并在完成后留下可行动的复盘。

## 功能

- 待办：每项待办必须有截止日期；可在主窗口中管理，也可一键变成透明、置顶的桌面悬浮清单。浮窗可拖动；锁定后鼠标会穿透到桌面，点击独立的小锁即可恢复操作。
- 正向计时：记录每件事情实际坚持的时长，完成后保存在本地记录中。
- 正向计时开始后会自动切换为透明、置顶的小窗，显示跳动时钟；小窗同样支持拖动、锁定穿透、暂停和完成记录。
- 倒计时：自行设置 1 至 720 分钟的专注时长，到点提醒后完成记录。
- 结束提醒：支持应用内弹窗、Windows 任务栏闪烁、声音提醒，以及导入本地自定义音效。
- 体验保护：加载失败会明确提示，删除待办或记录后可在短时间内撤销。
- 复盘摘要：记录页会显示今日专注、累计时长、活跃天数和待办完成情况。
- 任务闭环：待办支持时间、重要程度和编辑；完成专注时可同步完成关联待办。
- 数据掌控：支持本地备份、恢复、打开备份目录和清空当前数据。
- 趋势复盘：记录页增加最近 7 天的专注投入趋势。
- 今日驾驶舱：打开应用就能看到当前状态、下一件事和今天已经留下的进展。
- Focus Arc：用克制的状态视觉表达空闲、运行、暂停、休息和恢复，不打扰专注。
- 应用内命令面板：使用 `Ctrl/Cmd + K` 快速开始、暂停、完成专注或切换页面。
- 本地兼容：既有待办、正向计时、番茄钟和倒计时记录都会继续保留。
- 版本升级：v1 备份可自动迁移到 v2，恢复前会保留回滚备份并展示内容摘要。

## 日常使用

1. 在“待办”写下事项与截止日期。
2. 点击“专注”将待办带入计时页，或直接写下一轮要做的事。
3. 选择正向计时或倒计时，开始后在完成时保存记录。
4. 需要桌面提醒时，点击顶部“悬浮待办”，主窗口会隐藏，只留下透明置顶待办窗口。拖动标题区域调整位置；点击小锁开启穿透，再次点击独立的小锁解锁。
5. 开始正向计时后，主窗口会自动隐藏并保留专注小窗；完成记录后自动恢复主窗口。
